# Simple Chat Studio

A browser-based chat preview editor with editable Customer/Admin messages, timestamps, profile photos, chat image uploads from either side, receipt image upload, theme options, and an adjustable image watermark.

## Use
1. Extract the ZIP.
2. Open `Simple_Chat_Studio/index.html` in a modern browser.
3. Use the collapsed settings sections to keep the editor compact. Open a section only when needed.
4. Upload Customer or Admin chat images. Chat images are displayed in a compact 160×160 maximum preview so the conversation stays readable.
5. Upload a watermark image under “Watermark ပုံနှင့် Design”; adjust size, opacity, and position with sliders.
6. Use “Chat Image Download” to export the full chat canvas to PNG.

This is a local preview/design tool. It does not provide live messaging between separate Customer and Admin devices; that requires a backend and database.
